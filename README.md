# Coffee brew guide

A small site for choosing a coffee and following step-by-step instructions to make it on our machine. Built with the [Cool Graphs](https://github.com/CristinaDesign/cool-graphs) design system.

| What | Where |
|---|---|
| The site itself (open this file) | `index.html` |
| This site's design rules | `DESIGN-NOTES.md` |
| The coffee settings (from the whiteboard) | `data/coffee-settings.csv` |
| Design system copy (do not edit here) | `design-system/` |
| The designer's illustrations | `illustrations/` |

Status: the site is built (`index.html`, one self-contained file). It is published with GitHub Pages, which shows `index.html` as the website: Settings > Pages > Deploy from a branch > `main` / root.

Updated 23 November: the Start button now uses the design system's new **Action bar** (fixed at the bottom of the screen on a phone); the design system copy in `design-system/` was refreshed (Action bar, new unselected-card outline, lining numerals).

Motion: the design system copy now has the motion tokens; the Start bar slides up and buttons shrink slightly when pressed (all switched off for people who ask for reduced motion).
