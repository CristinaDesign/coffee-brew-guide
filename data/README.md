# Coffee settings

`coffee-settings.csv` holds the settings for each coffee, copied from the whiteboard. A spreadsheet program opens it directly.

| Column | Meaning | Unit |
|---|---|---|
| coffee | Name of the coffee as it appears on the site | |
| brand | Latera or Lavazza | |
| type | Regular or Decaf | |
| dose_g | Ground coffee in the basket | grams (g) |
| grind_setting | Number on the grinder | setting number |
| yield_ml | Liquid coffee in the cup | millilitres (ml) |
| time_seconds | Extraction time | seconds (s) |
| temperature_c | Water temperature | degrees Celsius (°C) |
| notes | Anything to know | |

Open questions: the "60" on the whiteboard is left out until we know what it is. There is no pre-infusion column, on purpose.
