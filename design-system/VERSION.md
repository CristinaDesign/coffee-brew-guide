# Cool Graphs snapshot

These files are a copy of the Cool Graphs design system (tokens and component styles), taken from
https://github.com/CristinaDesign/cool-graphs at commit `e764603` (2026-11-23).

- **Do not edit them here.** Change the design system in its own repository, then copy the new files over and update the commit above.
- The rules (principles, when to use which component, accessibility) are in that repository's `DESIGN.md`. This project's own rules are in `DESIGN-NOTES.md`.
- To update: copy `src/tokens/*.css` and `src/components/*/*.css` from the design system into these folders.
