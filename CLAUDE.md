# Instructions for AI tools

This is a small website for a coffee machine brew guide. The designer is a UX designer, not a developer: explain in plain language.

- Follow `DESIGN-NOTES.md` first, then the Cool Graphs rules. The Cool Graphs `DESIGN.md` and skill live in https://github.com/CristinaDesign/vegetablecharts (`DESIGN.md` and `.claude/skills/cool-graphs-design/SKILL.md`). Read them before building.
- Use only the tokens and components in `design-system/`. Do not edit those files here.
- Settings come from `data/coffee-settings.csv`. Never invent coffee settings.
- Every number has its unit next to it. Check light and dark, 400 px wide, contrast, 30 px targets and keyboard use.
- Update `README.md` when something changes.
